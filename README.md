# 📖 Project Overview

> [!NOTE]
> This application was developed as the Final Project for the **ACT AI Course**. The project focuses on solving real agricultural challenges in Pakistan through Artificial Intelligence and modern web technologies.

Kisan Companion Pakistan is an AI-powered smart agriculture platform designed to help farmers make better farming decisions.

The application combines Artificial Intelligence with practical farming resources, allowing users to explore crop information, pest & disease knowledge, government agriculture schemes, farming tips, and market prices through one modern, responsive web application.

The platform reduces the need to search across multiple websites by bringing essential agricultural resources together in one place.

---

# 🌟 Why This Project Matters

Agriculture contributes significantly to Pakistan's economy and supports millions of families.

However, many farmers still struggle because of:

- Limited access to agricultural experts
- Lack of organized farming information
- Low awareness of pest and disease management
- Difficulty accessing market prices
- Limited knowledge of government agriculture schemes
- Time-consuming information searches

Kisan Companion Pakistan addresses these challenges by providing a simple AI-powered digital farming assistant that makes agricultural knowledge easier to access.

# 🤖 AI Farming Assistant

The AI Farming Assistant is the core feature of this application.

It enables farmers to ask agriculture-related questions in natural language and receive intelligent, easy-to-understand responses powered by Artificial Intelligence.

## What the AI Assistant Can Do

- 🌾 Recommend suitable crops
- 🌱 Provide crop management guidance
- 💧 Suggest irrigation practices
- 🧪 Recommend fertilizers
- 🐛 Help with pest management
- 🌿 Promote sustainable farming
- 📚 Answer general agriculture questions

---

## Example Questions

Users can ask questions such as:

- Which crop is best for my soil?
- How can I increase wheat production?
- What fertilizer should I use?
- How can I prevent crop diseases?
- What is the best irrigation method?

# 🌱 Crop Library

The Crop Library provides organized agricultural information about important crops grown in Pakistan.

Each crop includes:

- Crop Overview
- Growing Season
- Suitable Climate
- Soil Requirements
- Water Requirements
- Fertilizer Recommendations
- Harvesting Information

This helps farmers make informed farming decisions before planting.

# 🦠 Pest & Disease Library

The Pest & Disease Library provides educational information about common agricultural pests and plant diseases.

- Symptoms

- Prevention Methods

- Organic Solutions
- Best Farming Practices

This feature helps farmers identify agricultural problems and learn preventive measures.

# ⚙️ Installation Guide

Follow these steps to run the project on your local machine.

## 📋 Prerequisites

Before getting started, make sure you have the following installed:

- Node.js (Latest LTS Version)
- npm or yarn
- Git

---

## 📥 Clone the Repository

```bash
git clone https://github.com/Hazrat-Noor/Kisan-Companion-Pakistan.git
```

---

## 📂 Navigate to the Project Folder

```bash
cd Kisan-Companion-Pakistan
```

---

## 📦 Install Dependencies

```bash
npm install
```

---

## ▶️ Run the Development Server

```bash
npm run dev
```

The application will start on your local development server.
